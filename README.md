# spine_app
Hakaton LCT_ 4 task


Для разворачивания системы предлагается использовать Docker. Контейнер находится на докер-хаб: https://hub.docker.com/r/gluhihdmitry/spine-app
Для загрузки следует использовать стандартный docker pull gluhihdmitry/spine-app

Вариант команды для запуска:
docker run -d --name spine-app -p 5000:5000 gluhihdmitry/spine-app:latest

Контейнер таким образом запущен на VPS сервере: http://134.0.113.206:5000/

Примеры визуализации работы системы: http://134.0.113.206:5000/examples (визуализация работы "на лету" на данный момент не предусмотрена)
